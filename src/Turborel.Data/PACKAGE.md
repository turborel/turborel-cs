# Turborel.Data

The ADO.NET data provider for [turborel](https://github.com/turborel/turborel),
a relational database system. It speaks turborel's native protocol,
version 1, in C#, with no native code and no dependency beyond .NET's own
libraries. It runs on .NET 10 and later, on Linux, macOS and Windows.

Turborel is in alpha, version 0.0.0, and so is this package. A driver's
version is the turborel release it is made for, the server's own number.
Anything may change from one build to the next. This package is not yet
published; it is built from source.
