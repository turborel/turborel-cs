# TurborelBatch

[Contents](README.md)

This page will describe `TurborelBatch`, the batch that sends several statements in one round trip over a pipeline, part of the driver's
standard interface, ADO.NET, async first: `TurborelDataSource`, `TurborelConnection`, `TurborelCommand`, `TurborelDataReader` and `TurborelFactory`. It is filled at milestone M7.
